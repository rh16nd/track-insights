# Area-weighted colours of every flag in public/flags/, one line per file:
#   <iso2> <hex>:<percent of the flag> ...   (largest first, >=6% only)
#   ... max:<hex>                            the flag's single brightest pixel
#   ... edges:<h>/<v>/<d> centre:<n>          how the flag is BUILT
#
# The brightest pixel is what decides how much of the flag can be shown behind
# the head band's text: it is the worst case the scrim has to survive, and for
# most nations it is plain white.
#
# `edges` is where the flag's edge energy points -- horizontal edges, vertical
# edges, diagonal edges, normalised to sum to 1. It is a Sobel-ish gradient over
# the same raster, binned by orientation, so Germany reads 1/0/0 (nothing but
# horizontal edges), France 0/1/0, Jamaica 0.06/0.00/0.94, and a Nordic cross
# reads ~0.58/0.41/0.01 -- both directions strong, no diagonals, which is a
# signature no other kind of flag has. `centre` is how far the middle of the
# flag is from its outer ring in RGB, which is what finds a device on a plain
# field: Japan 337, Korea 233, against 20 for the United States.
#
# The RULES that turn these into a motif live in make-flag-palette.py, not here.
# This file is measurements; that file is decisions.
#
# Measured, not eyeballed: each SVG was drawn into a 160x120 canvas and its
# pixels counted, so a big field of colour outranks a fiddly coat of arms.
# Reading the SVG fills instead would rank Spain's shield above its red, and
# would have no answer at all for the flags that use gradients.
#
# To regenerate (only needed when a flag file changes), run the site and
# paste this into the browser console:
#
#   const cv = document.createElement("canvas"); cv.width = 160; cv.height = 120;
#   const ctx = cv.getContext("2d", { willReadFrequently: true });
#   const hex = (n) => n.toString(16).padStart(2, "0");
#   for (const c of CODES) {                       // the iso2 list below
#     const img = new Image(); img.src = "/flags/" + c + ".svg"; await img.decode();
#     ctx.clearRect(0, 0, 160, 120); ctx.drawImage(img, 0, 0, 160, 120);
#     const d = ctx.getImageData(0, 0, 160, 120).data, bins = new Map(); let n = 0;
#     for (let i = 0; i < d.length; i += 4) {
#       if (d[i + 3] < 128) continue;
#       const k = ((d[i] >> 4) << 8) | ((d[i+1] >> 4) << 4) | (d[i+2] >> 4);
#       const b = bins.get(k) || [0,0,0,0];
#       b[0] += d[i]; b[1] += d[i+1]; b[2] += d[i+2]; b[3]++; bins.set(k, b); n++;
#     }
#     ...top 4 bins by count, averaged, as hex:percent
#   }
#
# The 4-bit-per-channel bins collapse anti-aliased edges into the colour they
# were drawn from; each bin's hex is the mean of the real pixels in it.
